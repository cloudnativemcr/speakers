# Cloud Native Manchester 🐝

We are an active Cloud Native + Kubernetes meetup community for Manchester, UK.

## Meetups

Please join the CNCF Manchester Chapter on the [CNCF Community](https://community.cncf.io/cloud-native-manchester/).

If you are currently registered with the [meetup.com page](https://www.meetup.com/cloud-native-kubernetes-manchester/), we kindly ask that you also register for the Cloud Native Manchester group on the [CNCF Community](https://community.cncf.io/cloud-native-manchester/) and use that page to register for future events.

### What to Expect

If you're a first-timer, the typical format is: doors open from 6 PM, talks from 7 PM. We typically host two talks, with a break in between.

## Speaker submissions

We currently support speaker submissions via GitHub or email.

### Via GitHub

We accept speaker proposals via GitHub issues.

Please use this repository to submit a talk proposal by [opening an issue](https://github.com/cloudnativemcr/speakers/issues/new?&labels=&template=talk-submission-template.md&title=).

One of the [organisers](https://github.com/orgs/cloudnativemcr/people) will then jump in to discuss and arrange a date.

### Via Email

Alternatively, you can submit your talk via email at [contact@cloudnativemcr.co.uk](mailto:contact@cloudnativemcr.co.uk) and one of the organisers will get back to you.

When doing so, please ensure you include the following details:

```
* **Title**: 
* **Speaker**: 
* **Type**: (Presentation 30-45 mins | Lightning Talk 5-10 mins)
* **Level**: (basic | standard | advanced)
* **Tags**: (e.g. kubernetes, devops, live-coding, workshop)

**Description**

*Please provide a short paragraph that describes your proposal*

**Speaker Bio** (optional)

*A short bio of the speaker*
```

## Code of Conduct

As a CNCF community group, all attendees, speakers, sponsors, and volunteers are required to follow the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). We are committed to providing a welcoming and inclusive experience for everyone. If you experience or witness any unacceptable behaviour, please contact the [organisers](mailto:contact@cloudnativemcr.co.uk).
